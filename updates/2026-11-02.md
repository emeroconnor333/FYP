## Literature Review

### Floating point arithmetic core concepts

#### IEEE Standard for Floating-Point Arithmetic (IEEE 754-2019)
- Specifies binary and decimal floating-point formats, the basic operations (including fused multiply-add), rounding attributes, exception handling, and recommended operations for interchange and reproducible results in computer programming environments.

#### What Every Computer Scientist Should Know About Floating-Point Arithmetic (Goldberg 1991)
- A tutorial on floating-point arithmetic for computer scientists.

#### Handbook of Floating-Point Arithmetic (2nd ed.) (Muller et al. 2018)
- An overview of modern floating-point arithmetic.

### Detection tools for FP variability

#### Estimation of numerical reproducibility on CPU and GPU (Jézéquel et al. 2015)
- DSA (Discrete Stochastic Arithmetic) enables one to estimate rounding error propagation in simulation programs. In this paper, it is shown that DSA can be used to estimate which digits in simulation results may be different from one environment to another because of rounding errors. 

#### PLINER: Isolating lines of floating-point code for compiler-induced variability (Guo et al. 2020)
- PLINER, a tool to automatically pinpoint code lines that trigger compiler-induced variability

#### FLiT: Cross-platform floating-point result-consistency tester and workload (Sawaya et al. 2017)
- FLiT (Floating-point Litmus Tester) is a tool that takes in a "kernal" of code (e.g. a function), and detects how variable floating point results will be across compilers.

### CERN/High-energy physics software

#### Floating-point profiling of ACTS using Verrou (Grasland et al. 2019)
- Verrou, a Valgrind-based tool for dynamic instrumentation of floating-point computations, was applied to the ACTS codebase for the dual purpose of evaluating its numerical stability and investigating possible avenues for use of reduced-precision arithmetic.
